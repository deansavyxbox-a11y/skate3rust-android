# On-device ISO converter runtime

The direct Xbox 360 ISO importer runs the repository's existing Python asset converters inside the Android app. Chaquopy 17.1.0 embeds Python 3.13 for `arm64-v8a`; the build pins NumPy 1.26.2 and Pillow 11.0.0 to the Android wheels published by Chaquopy. This combination matches the project's Python/NumPy/Pillow converter requirements and Android's minimum API 26. It is included only in the Android application.

The Gradle build stages a curated set of public converter `.py` and metadata files under `android/build/generated`. It excludes test modules, Blender tooling, all extracted game data, and private caches. At import time the service copies those sources into app-private cache, then starts Python on demand. The source ISO is first copied into app-private storage, parsed/extracted by the Rust XDVDFS reader, converted serially, checked by the renderer-free Rust validator, and published through the same integrity manifest and recovery journal as a prepared ZIP.

The converter dependencies are resolved from Chaquopy's Android package index. Their upstream references are [Chaquopy 17.1 compatibility and build documentation](https://chaquo.com/chaquopy/doc/current/android.html), [NumPy Android wheels](https://chaquo.com/pypi-13.1/numpy/), and [Pillow Android wheels](https://chaquo.com/pypi-13.1/pillow/). Vendored converter notices are staged with their corresponding sources. A private full ISO subsequently passed conversion and publication on the RedMagic 10 Pro; see [the validation report](ISO_IMPORT_VALIDATION.md) for evidence and limitations. The bundle preserves the tools package hierarchy and uses the existing bounds-checked Rust RefPack decoder from the Android import library.
