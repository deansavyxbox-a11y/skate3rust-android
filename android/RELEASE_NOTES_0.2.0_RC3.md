# Skate3Rust Android 0.2.0-rc3

Experimental prerelease, package `com.skate3rust.android`, version code 4. This release fixes the direct ISO import progress display. During conversion, the setup screen now updates its current step and map count, and does not show a misleading `0.0 MB` for work whose byte total is unknown. Copying and extraction still show measured bytes. Import conversion output and installed game assets are unchanged. See the [progress investigation and phone validation](ISO_PROGRESS_VALIDATION.md).

Install this APK over `0.2.0-rc2` to retain imported assets, settings and touch layout. The package ID, development signing certificate, minSdk 26, targetSdk 35, ARM64 ABI and Vulkan requirement remain unchanged. This is still a debuggable build because the current asset installer uses Android `run-as`. Contributor builds signed with another certificate may not update it. No proprietary Skate 3 assets are bundled.

The progress change completed a second direct ISO import on RedMagic 10 Pro (Android 16), and University rendered afterward. Retroid Pocket 3 Plus (Android 11) installed the rc2 public APK, imported a prepared ZIP and rendered StartPark, but University was killed by Android under memory pressure; rc3 is not a fix for that. The reports from vivo 1726 and Samsung Galaxy A6+ still lack ADB failure codes, so their causes are unknown. The embedded FreeType library still has 4 KB ELF alignment; 16 KB page-size support is not cleared. Other device compatibility is unverified.
