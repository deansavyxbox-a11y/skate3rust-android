# Skate3Rust Android 0.2.0-rc4

Experimental ARM64 Android prerelease, package `com.skate3rust.android`, version code 5. This update makes Android use Bevy's uniform-buffer path for skinned meshes. In [issue #1](https://github.com/deansavyxbox-a11y/skate3rust-android/issues/1), a Galaxy Z Fold 5 tester reported that the matching diagnostic build corrected a distorted skater and restored expected movement. The exact rc4 APK has not been tested on that Fold 5; broader Android compatibility is not established.

Install over rc3 or the `rc3-skin-test1` diagnostic build to retain imported assets, settings and touch layouts. The package ID and signing certificate remain the same; version code rises from 4 to 5. Android 8 / API 26, ARM64 and compatible Vulkan are still required. This remains a debuggable development-signed APK because the importer uses Android `run-as`. Contributor builds with a different certificate may not update in place. Android does not normally permit an in-place downgrade from rc4 to rc3; keep a backup of your assets and settings before considering removal. No proprietary Skate 3 assets are included.

The rc3 ISO progress display and on-phone prepared ZIP / ISO import remain. The Retroid Pocket 3 Plus University low-memory result, 16 KB page-size alignment limitation and other [known limitations](../README.md#known-limitations) are not addressed by this change.

## Validation

The native Android build and Android unit-test task completed. The candidate APK is 78,123,332 bytes with SHA-256 `fdbf2f42b4c92d0d21aed5fc82ea2da22f5a6f85c925a03588887f1bb99ce36a`. ZIP CRC, APK signature and 16 KB ZIP alignment checks passed. Package metadata reports version code 5, minSdk 26, targetSdk 35, ARM64 native libraries and a required Vulkan feature. The signing certificate SHA-256 is `82f0ecd863190a2e9224ad2be18455552a7c7804395d6949a80d4b701c7a4a81`, matching rc3. No `.iso`, `.xex`, `.xbe`, `.pak` or `.skate` game-data entries are bundled. The GitHub download must be checked separately after publication.

On RedMagic 10 Pro (Android 16), ADB installed this exact candidate over the diagnostic build with `Success`. The installed version changed to rc4; hashes of the imported-asset manifest, selected-map setting, graphics setting and touch layout were identical before and after installation. BlackBoxPark and DownTown loaded with intact skater and environment rendering. Touch pushing moved the skater in BlackBoxPark, with no fatal Android or native error in the observed log. Screenshot FPS readings during this short check ranged from about 54 to 91; they do not establish sustained performance or parity with rc3. The owner confirmed controller input on the preceding diagnostic build, but controller input was not retested on this exact rc4 APK. A fresh install, full ISO import and a Fold 5 run of the exact rc4 package remain untested.
